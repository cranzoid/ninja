# Regime Engine Service

Classifies current market regime as green, mixed, or stressed using: NIFTY 50 trend state, breadth metrics, volatility (India VIX / realized-vol proxy), gap frequency, sector leadership concentration, and correlation dynamics.

Regime output drives sizing multipliers across the platform.

See [PROJECT_CHARTER_V2.md](../../docs/PROJECT_CHARTER_V2.md) §6.7 for regime stack details.
