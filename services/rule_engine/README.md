# Rule Engine Service

Deterministic authority layer — no model output can place, resize, or loosen risk alone. Enforces all trading rules including:

- Risk limits (per-trade, position caps, sector caps, aggregate open risk)
- Event and blocker rules (S1-S5, R1-R5)
- Entry/exit discipline for Core and Swing strategies
- Regime-adjusted sizing
