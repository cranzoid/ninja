# Candidate Engine Service

Screens the universe to produce shortlisted trade candidates based on entry criteria for both Core (price > 200-DMA, not extended, fundamental quality) and Swing (price > 50-DMA, 50 > 200, breakout, volume confirmation) strategies.

Outputs candidates for blocker scanning and rule engine evaluation.

See [PROJECT_CHARTER_V2.md](../../docs/PROJECT_CHARTER_V2.md) §6.4 and §6.5 for entry rules.
