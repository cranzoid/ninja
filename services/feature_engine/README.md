# Feature Engine Service

Computes technical indicators and derived features from raw market data: moving averages (50-DMA, 200-DMA), ATR(14), volume ratios, breadth metrics, and other signal-lane outputs.

All features are recalculable and versioned.

See [PROJECT_CHARTER_V2.md](../../docs/PROJECT_CHARTER_V2.md) §6 and §9 for feature requirements.
