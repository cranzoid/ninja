# Audit Ledger Service

Records every decision, action, and state change as first-class audit events. Provides the ground truth for reconciliation (intents ↔ simulated fills ↔ portfolio state) and operator visibility.

Every trade must be explainable and audit-ready.

See [PROJECT_CHARTER_V2.md](../../docs/PROJECT_CHARTER_V2.md) §4 and §15 for audit requirements.
